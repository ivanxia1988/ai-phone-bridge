# 使用指南

## 运行范围

目前完整实测组合是 macOS、ESP32-D0WDQ6-V3（4 MB Flash、板载 CP2102）和 iPhone 14。USB-C 接电脑，手机蓝牙连接 ESP32。固件用 UART0 / 921600 波特率传输，不需要外接 I2S DAC，OLED 不参与通话。

控制台保存 Key 的功能依赖 macOS 钥匙串，其他系统的网页运行方式尚未适配。建议 Python 3.11 或更高版本。需要 C 编译器和 Node.js 才能执行全部开发测试；macOS 可安装 Xcode Command Line Tools 并准备 Node.js。

## 1. 安装依赖

在仓库根目录运行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt platformio pytest esptool
```

## 2. 构建、备份与烧录

先构建，确认工具链可用：

```sh
PLATFORMIO_CORE_DIR="$PWD/.pio-core" .venv/bin/pio run -d firmware
.venv/bin/python -m serial.tools.list_ports
```

找出实际串口。本机实测 CP2102 使用 `/dev/cu.SLAB_USBtoUART`；其他设备路径会不同。不要同时开串口监视器、运行通话服务和烧录。

已有固件的板子，先按实际 Flash 大小备份。以下命令仅适用于本项目实测的 **4 MB** 板子，`你的串口路径` 必须替换：

```sh
mkdir -p work/backups
.venv/bin/esptool --port '你的串口路径' --baud 115200 \
  read-flash 0 0x400000 work/backups/before-install.bin
chmod 600 work/backups/before-install.bin
```

完整 Flash 可能包含配对记录等个人数据，请只在本机保存。备份成功后烧录：

```sh
PLATFORMIO_CORE_DIR="$PWD/.pio-core" .venv/bin/pio run -d firmware \
  -t upload --upload-port '你的串口路径'
```

不需要默认擦除整片 Flash。烧录流程写入引导程序、分区表与应用。首次工具链下载需要时间。

## 3. 配对手机与启动页面

在 iPhone「设置 → 蓝牙」连接 **ESP32 Phone Bridge**。打开串口可能复位板子，必要时在服务启动后再次连接。

```sh
.venv/bin/python -m phone_bridge.ui --background
```

打开 <http://127.0.0.1:8787>，或双击仓库里的 `启动电话控制台.command`。

## 4. 配置 AI 源

- **豆包 O2**：使用豆包语音控制台的 API Key，不是火山方舟文本模型的 Key。默认音色 VV，也可填入自己有权限使用的音色 ID。默认模型版本 `1.2.1.1`，具体可用性取决于账户。
- **OpenAI Realtime**：使用自己的 OpenAI API Key。默认模型配置为 `gpt-realtime-2.1`，可通过 `OPENAI_REALTIME_MODEL` 选择账户有权限使用的模型。

各渠道 Key 单独保存在 macOS 钥匙串，页面和偏好文件不返回或记录明文。选择渠道、保存 Key 后点击“连接设备并检测渠道”，不会拨号。切换渠道或音色后重新检测。

需要手动提供凭证时，可用终端命令 `.venv/bin/python -m phone_bridge setup --provider doubao` 或 `--provider openai`，按不回显的提示输入。不要把 Key 放进 Issue、Prompt 或公开截图。

接口参考：[豆包端到端实时语音](https://www.volcengine.com/docs/6561/1594356)、[OpenAI Realtime WebSocket](https://developers.openai.com/api/docs/guides/realtime-websocket)。

## 5. 填写任务并通话

使用你获准联系的完整号码。Prompt 示例：

```text
你是我的 AI 助手，请用中文沟通，开场说明 AI 身份和录音用途。
这次只确认我们已经约定的周五下午 3 点是否方便。
如果对方不方便，询问一个替代时间并复述确认。
不要承诺我没有授权的事项；任务完成后简短道别并结束。
```

所有检测通过后点击“开始 AI 通话”。可以随时点击“结束通话”。失败不会自动重拨。初次体验建议用自己控制的另一部手机，检查双向声音、延迟、打断及挂断结果。

内置猎头案例只填写 Prompt，不会点击后直接拨号。没有确认的职位、薪资或待遇，不要加入任务中让模型承诺。

## 6. 查看结果

记录保存在 `calls/<通话编号>/`，网页可播放和下载双方 WAV，查看转写及总结。

| 文件 | 说明 |
| --- | --- |
| `result.json` | 通话状态、错误及挂断确认 |
| `remote.wav` | 实际收到的对方声音 |
| `agent.wav` | 电脑发往手机的 AI 声音 |
| `transcripts.jsonl` | 实时文字和打断标记 |
| `recording-transcripts.json` | OpenAI 为录音二次转写；豆包采用注明来源的实时转写 |
| `summary.md` | 基于对应转写的总结 |

模型生成文字可能早于音频播放，被打断的文字不一定已经说出；重要信息需要对照录音确认。USB 拔出后不能保证手机已经挂断，应检查结果并确认手机状态。

## 7. 蓝牙自动重连

固件记住最后成功建立 HFP 的已配对手机。没有已保存目标且只有一台已配对手机时可以选用；多台时请先手动连接目标手机。

底层报告超时或关机等原因时允许重试；明确主动断开和鉴权失败时暂停。成功手动连接或重启板子可恢复自动重连。重试检查间隔约 5.12 秒，加上连接超时和断线检测，不能保证手机回来后 5 秒内恢复。

协议命令 `bt_disconnect` 暂停并断开蓝牙，`bt_reconnect` 恢复尝试。命令不拨号，也不恢复旧通话。协议状态保持 `firmware=1`，重连版本增加 `bt_build=2`、`bt_auto`、`bt_retry`。这些是底层串口命令，当前网页尚未提供专用按钮；请勿让独立串口工具与通话服务同时占用设备。

## 8. 开发检查

```sh
.venv/bin/python -m pytest -q
PLATFORMIO_CORE_DIR="$PWD/.pio-core" .venv/bin/pio run -d firmware
```

软件测试通过不能代替实际电话和超距返回测试。已有实测与待验证项见 [验证记录](validation.md)。
