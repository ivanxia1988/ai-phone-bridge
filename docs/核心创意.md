# 技术方案：让 AI 接上现有手机和号码

项目通过蓝牙通话接口，将电脑上的实时语音 AI 接到现有手机，使用手机自身的线路和号码发起真实电话。

实现上，ESP32 模拟蓝牙免提耳机，通过 USB 与电脑交换音频及控制指令。Python 服务对接豆包 O2 和 OpenAI Realtime，再把模型声音送回手机。

## 功能

1. 把硬件音频桥接做成可操作的中文控制台，包含连接检查、开始、结束和结果回看。
2. 接入两家实时语音 AI，在相同硬件链路上切换，便于探索不同声音和对话体验。
3. 支持 Prompt，让使用者明确设置身份、风格、具体任务和结束条件。
4. 加入蓝牙主动重连，减少已配对手机恢复可连接后仍需手动操作的情况。
5. 保留双向录音、转写、总结与状态，便于判断一次沟通有没有真正完成。

“自动重连”指连接恢复，不是自动跟进联系人，也不是感知精确距离。固件会尝试连接最后成功连接且仍在配对记录中的手机；明确主动断开或鉴权失败时暂停。启动连接与命令暂停/恢复已实测，超距后返回仍待实测。

## 验证范围与来源

豆包 O2 与 OpenAI Realtime 均已完成真实电话测试。语音延迟、打断、卡顿、重连条件和设备兼容性仍需持续验证；已有结果与限制见 [验证记录](validation.md)。

蓝牙 HFP 音频桥接基于上游开源实现。本项目补充电脑端 AI 服务、中文控制台、双渠道、Prompt、结果记录与主动重连。来源与许可证范围见 [NOTICE](../NOTICE.md)。
